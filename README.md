# LectureNote AI — приватная библиотека конспектов видеолекций

Локальное Django-приложение проекта **«Автоматическое конспектирование видеолекций»**. Пользователь загружает видео, обработка выполняется в фоне, а результат отображается как PDF-конспект с текстом и выбранными кадрами.

## Что реализовано

- регистрация, вход и выход пользователя;
- показ/скрытие вводимого пароля на страницах входа, регистрации и смены пароля;
- профиль пользователя: добавление или изменение email для уведомлений, изменение пароля;
- приватная библиотека конспектов: публичного каталога и признака публичности в актуальной модели нет;
- отдельная страница избранных конспектов;
- теги: список задаёт администратор, пользователь назначает их только своим видео/конспектам;
- загрузка видео и выполнение тяжелого ML-пайплайна через Celery;
- уведомление в личном кабинете и отправка письма на указанный email;
- автоматическое удаление загруженного видео после завершения обработки или ошибки;
- итоговый PDF-конспект со встроенным просмотром на странице материала;
- защищённая выдача PDF, markdown и транскрипции только владельцу;
- удаление конспекта после отдельного подтверждения с удалением его файлов;
- личный отзыв о полученном результате: добавить, изменить или удалить оценку и комментарий;
- обновлённый адаптивный интерфейс с боковой навигацией, карточками, статусами и страницами аккаунта.

## Приватность данных

В рабочей модели `LectureNote` отсутствует поле `is_public`; публичная страница конспектов удалена. Интерфейс пользователя строится только на связи `user.lecture_notes`, то есть на его личной библиотеке. PDF, markdown, транскрипция, журнал обработки, теги, избранное, отзыв и удаление доступны только владельцу материала.

В архиве оставлена миграция `0005_private_library_review_and_indexes.py`, потому что она нужна для безопасного обновления базы, созданной предыдущей версией прототипа: миграция удалит устаревшее поле публичности и преобразует прежние оценки в личные отзывы владельца. После выполнения миграций в актуальной схеме признака общей базы нет.

## Связь с существующим ML-пайплайном

В `summaries/services/pipeline.py` серверный адаптер вызывает реализованные в проекте этапы:

- `text_processing.audio.split_audio_video`;
- `transcribe_worker.py`;
- `image_processing.detect_ROI_with_metrics.content_selector.extract_content_keyframes`;
- `image_processing.keypoints_roi.detect_keypoints_for_images`;
- `utils.crop_frames_by_keypoints`;
- `image_processing.OCR.run_ocr`;
- `multimodal_summary.build_multimodal_summary`.

Твои ML-модули нужно оставить в исходной папке проекта и указать её в `.env`:

```env
PIPELINE_ROOT=D:/path/to/current/project
KEYPOINTS_MODEL_PATH=D:/Disk C/data/media/slide_dataset/output/best.weights.h5
DEFAULT_LLM_MODEL=qwen
```

Django/Celery временно запускает ML-код из `PIPELINE_ROOT`, чтобы LLM работала с теми же относительными путями и настройками, что и при запуске через `main.py`.

## Установка и запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python manage.py migrate
python manage.py createsuperuser
```

Запусти Redis:

```bash
docker compose up -d redis
```

Запусти веб-приложение:

```bash
python manage.py runserver
```

Запусти Celery **из того же окружения, где работает `main.py` и LLM**:

```bash
celery -A config worker -l info --pool=solo
```

## Обновление с предыдущей версии архива

Замените файлы приложения и выполните:

```bash
python manage.py migrate
```

Миграция:

- удалит устаревшее поле `is_public`;
- сохранит существующие приватные конспекты;
- удалит отзывы, оставленные не владельцем материала в старой версии;
- преобразует оценивание в один личный отзыв владельца на конспект;
- добавит индексы для личной библиотеки и избранного.

## Основные страницы

| Страница | Назначение |
|---|---|
| `/dashboard/` | Личная библиотека конспектов |
| `/favorites/` | Избранные конспекты |
| `/upload/` | Загрузка видео |
| `/notes/<id>/` | Встроенный PDF, теги и личный отзыв |
| `/notes/<id>/delete/` | Подтверждение удаления |
| `/notifications/` | Уведомления |
| `/accounts/profile/` | Email и переход к смене пароля |
| `/accounts/password-change/` | Смена пароля |
| `/admin/summaries/tag/` | Управление доступными тегами администратором |

## PDF и изображения

Итоговые файлы называются по пользовательскому названию конспекта, например:

```text
Лекция 1. Вероятность.md
Лекция 1. Вероятность.pdf
```

PDF создаётся через WeasyPrint. Если импорт WeasyPrint на Windows не проходит из-за нативных библиотек, автоматически используется fallback на ReportLab; изображения из markdown также добавляются в PDF.

## Удаление видео и конспектов

Исходный видеофайл очищается в блоке `finally` фоновой задачи — и после успеха, и после ошибки. Конспект пользователь может удалить после завершения обработки или ошибки; при подтверждении удаляются PDF, markdown, транскрипция, логи, уведомления и личный отзыв.
